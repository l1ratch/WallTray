## 🌟 Ключевые возможности

- ☀️ **Bing Image of the Day**:
  - Ежедневные официальные обои Microsoft в максимальном разрешении **4K UHD (3840×2160)**.
  - Поддержка выбора региона контента (`ru-RU`, `en-US`, `de-DE`, `fr-FR`, `ja-JP`, `zh-CN`).
  - Просмотр исторического архива обоев за предыдущие дни и месяцы из открытого репозитория.
- 🌊 **Каталог Wallhaven.cc**:
  - Полноценная интеграция открытого каталога Wallhaven.
  - Наглядные фильтры категорий (*General*, *Anime*, *People*).
  - Быстрый поиск по тегам (*nature*, *space*, *cyberpunk*, *landscape*, *minimalism*, *cars*, *fantasy*).
  - Фильтрация по разрешениям экрана (*Full HD*, *2K QHD*, *4K UHD*, *UltraWide 21:9*).
- 🖥️ **Поддержка любых мультимониторных конфигураций**:
  - Автоматическое определение реального физического разрешения, частоты обновления (Гц) и соотношения сторон каждого подключенного экрана.
  - Функция автоподбора обоев под мониторы в один клик.
- ⏱️ **Умная и гибкая автосмена обоев**:
  - Смена по интервалу (15м, 30м, 1ч, 2ч, 6ч, 12ч, 24ч или произвольный интервал).
  - Смена при запуске системы или комбинация интервала и старта.
  - Источники для автосмены: *Сегодняшние Bing* (раз в сутки при появлении новых обоев), *Случайные Bing*, *Каталог Wallhaven* или *Избранное*.
  - Применение настроек автосмены «на лету» без перезапуска приложения.
- 🖱️ **Удобное контекстное меню трея (ПКМ)**:
  - Современное меню в стиле Windows 11 Fluent с чёткими векторными иконками.
  - Быстрая смена обоев в один клик прямо из трея.
  - Быстрое переключение режимов: фиксация текущих обоев и пауза автосмены.
- ⭐ **Быстрое избранное и надежный кэш**:
  - Добавление и удаление обоев в избранное в один клик со звёздочкой.
  - Изоляция кэша в `%LocalAppData%\WallTray`, что исключает конфликты и зависания при синхронизации с облаком (OneDrive).
  - Гарантированная защита избранного: очистка кэша удаляет только временные файлы, сохраняя избранные обои.
- 🚀 **Бесшовные автообновления (Velopack)**:
  - Автоматическая проверка новых релизов с поддержкой дельта-патчей (всего 100–150 КБ трафика).
  - Фоновое скачивание с индикатором прогресса и мгновенный перезапуск прямо из трей-окна.
  - Возможность участия в канале предварительных сборок (*Preview/Beta*).
- 🎨 **Современный интерфейс Windows 11 Fluent**:
  - Тёмная матовая тема с акриловыми эффектами и плавными анимациями.
  - Сверхтонкие плавающие скроллбары (5px в стиле iOS / macOS).
  - Чёткая векторная графика (SVG/Path) без размытия при любом масштабе экрана (DPI).

## 📥 Установка и запуск

### Способ 1: Автоматический установщик Velopack (Рекомендуется)
1. Скачайте `WallTray-win-Setup.exe` (или `WallTray-stable-Setup.exe`) со страницы [Релизов](https://github.com/l1ratch/WallTray/releases).
2. Запустите установщик. Приложение автоматически установится, создаст ярлыки в меню «Пуск» и запустится в системном трее.
3. Все последующие обновления доставляются инкрементальными дельта-патчами и применяются бесшовно.

### Способ 2: Портативная версия (Portable)
1. Скачайте архив `WallTray-win-Portable.zip` со страницы [Релизов](https://github.com/l1ratch/WallTray/releases).
2. Распакуйте в любую папку и запустите `WallTray.exe`. Программа не требует прав администратора и не вносит изменений в реестр.
3. **Режимы работы портативной версии**:
   - **Обычный режим (по умолчанию)**: программа использует единую общую базу данных и настроек в `%LocalAppData%\WallTray`. Если на компьютере параллельно используется установленная версия, все настройки, история и избранное будут автоматически синхронизированы.
   - **Изолированный режим (True Portable)**: если создать рядом с `WallTray.exe` папку `data` или пустой файл `portable.dat` (например, при запуске с USB-флешки на чужом компьютере), программа будет сохранять все настройки, базу данных и скачанные обои исключительно в эту локальную папку, не оставляя следов на хост-системе.

## 🛠️ Сборка из исходного кода

### Требования:
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Velopack CLI](https://velopack.io) (устанавливается командой `dotnet tool install -g vpk`)
- Windows 10 (1809+) или Windows 11 (x64)

### Сборка и тестирование:

```powershell
# 1. Клонирование репозитория
git clone https://github.com/l1ratch/WallTray.git
cd WallTray

# 2. Запуск автоматических тестов (15 unit-тестов)
dotnet test

# 3. Быстрая компиляция приложения для локального тестирования
dotnet publish BingWallTray.App/BingWallTray.App.csproj -c Release -r win-x64 --no-self-contained -o ./publish/win-x64

# 4. Сборка полного Velopack релиза (инсталлятор + дельта-пакеты + портативный архив)
./build-release.ps1 -Version 26.8.2
```

## 🏗️ Архитектура и стек технологий

- **Платформа**: .NET 8.0 (Windows Desktop SDK).
- **UI Framework**: Windows Presentation Foundation (WPF) с кастомной темой Fluent Dark.
- **Архитектура**: Model-View-ViewModel (MVVM) с разделением ответственности сервисов и реактивной шиной событий `SettingsChanged`.
- **Хранение данных**: Атомарный `WallpaperCacheService` с защитой от повреждения файлов (`.bak` резервные копии и файловые блокировки).
- **Схема версионирования**: Календарное версионирование (**CalVer**) в формате `YY.M.Patch` (например: `26.8.2`).
