# Описание программы BingWallTray

**BingWallTray** — это современное, легкое и оптимизированное Windows-приложение для автоматической смены обоев рабочего стола на основе ежедневной подборки изображений поискового сервиса Bing. Программа выполнена в виде фонового процесса, находящегося в системном трее и предоставляющего удобный доступ к выбору обоев через компактное Flyout-окно.

---

## 1. Как выглядит интерфейс приложения

Интерфейс программы спроектирован строго по гайдлайнам **Fluent Design (Windows 11 Dark Mode)**:
*   **Главное окно (Flyout)**: Эстетичное темное окно увеличенного размера (**460x680**), которое плавно выдвигается из правого нижнего угла (или левого, в зависимости от расположения панели задач) при одиночном нажатии левой кнопкой мыши (ЛКМ) по иконке в трее. При клике вне окна оно автоматически прячется.
*   **Тонкие Fluent-скроллбары**: Во всех прокручиваемых областях (Галерея, Настройки, Избранное, Детали обоев) стандартные широкие белые полосы прокрутки заменены на современный тонкий плавающий скроллбар (шириной 6px), который проявляется только при прокрутке и не сжимает содержимое.
*   **Элементы управления**:
    *   **Галерея обоев (Главный экран)**:
        *   Сетчатый макет (**UniformGrid в 2 колонки**), отображающий 8 ежедневных обоев Bing в виде красивых закругленных плиток высотой **130px**.
        *   **Двойной клик** по плитке мгновенно скачивает ее в максимальном разрешении и устанавливает фоном рабочего стола.
        *   Постоянный зеленый индикатор `✓ АКТИВНО` в левом верхнем углу для примененных в данный момент обоев.
        *   **Всплывающий оверлей**: при наведении курсора на плитку плавно появляется темная подложка, содержащая краткое название обоев, кнопку быстрого добавления в избранное (звезда ★) и кнопку перехода к информации (ℹ).
    *   **Экран деталей обоев (ℹ)**:
        *   Вызывается кликом по кнопке `ℹ` на плитке.
        *   Содержит крупный просмотр изображения (высота 300px) с индикатором `УСТАНОВЛЕНО`.
        *   Подробный блок сведений: крупный заголовок обоев, подробная информация об авторском праве (копирайт) и кликабельная ссылка на страницу описания Bing.
        *   Кнопки быстрого применения («Установить обоями») и добавления в избранное (★).
    *   **Страница «Избранное» (★)**:
        *   Вызывается кликом по золотой звездочке в шапке окна. Кнопка «Назад» (←) возвращает в галерею.
        *   **Пустое состояние**: Если избранных обоев нет, красиво выводится крупная звезда и подсказка о том, как добавить картинки.
        *   **Список карточек избранного**: Карточки оформлены в виде аккуратных скругленных темно-серых плиток с превью обоев `100x62px`, заголовком и тремя кнопками управления (применить, показать в проводнике, физически удалить).
    *   **Страница настроек (⚙)**:
        *   Вызывается кликом по шестеренке в шапке окна.
        *   **Чекбоксы (Переключатели)** оформлены как плавные Toggle-switches в стиле Windows 11.
        *   **Логирование и обслуживание**: Секция для настройки уровня ведения логов и кнопки мгновенной очистки (логи, кэш).
    *   **Страница «О программе» (ℹ)**:
        *   Минималистичный экран с крупным логотипом приложения (96x96), информацией о версии и кнопкой проверки обновлений на GitHub.
*   **Контекстное меню (ПКМ)**:
        *   Строгое Fluent-меню с тенью и закругленными краями, открывающееся по нажатию правой кнопкой мыши по трею. Содержит быстрые переключатели автосмены, паузы, фиксации обоев, кнопку быстрого открытия папки скачивания и пункт выхода из программы.

## 2. Как работает приложение (Бизнес-логика)

*   **Фоновый планировщик (`SchedulerService.cs`)**:
    Запускается при старте Windows, регулярно обращается к API Bing для получения 8 последних обоев.
*   **Умное кэширование и пропуск запросов**:
    Если приложение перезапускается, а подборка на сегодня уже скачана и сохранена в кэш-файле, сетевой опрос Bing API полностью блокируется. Это снижает нагрузку на сеть до нуля.
*   **Обработка качества UHD/4K**:
    Приложение анализирует ссылки Bing и автоматически заменяет параметры сжатия на максимальные, скачивая обои в оригинальном Ultra HD качестве.
*   **Мгновенный рендеринг интерфейса (Миниатюры)**:
    Для минимизации трафика и мгновенного открытия окна WPF использует легковесные свойства `ThumbnailUrl` (размер 240x135, вес ~7 КБ) и `PreviewUrl` (размер 800x450, вес ~50 КБ). Оригинальный файл UHD-обоев скачивается на диск только при установке на рабочий стол.
*   **Физическое удаление файлов избранного**:
    При добавлении обоев в избранное они скачиваются в папку загрузок и защищаются от автоматической очистки. При снятии отметки избранного (нажатие 🗑 в списке избранного или повторное нажатие ★ на плитке) программа **физически стирает файл обоев с жесткого диска компьютера**, освобождая дисковое пространство. Неизбранные старые обои очищаются автоматически раз в день.
*   **Регистрация автозагрузки**:
    Реализована запись в реестр Windows (`Software\Microsoft\Windows\CurrentVersion\Run`). При запуске системы приложение стартует скрытно (тихий режим) — в трее появляется иконка, но главное окно не выскакивает на экран, не отвлекая пользователя.

## 3. Сравнительный анализ: изменения по сравнению с исходным ТЗ

Разработка велась итеративно. Пожелания пользователя существенно улучшили эргономику и внешний вид программы.

| Функция / Элемент | По исходному ТЗ | Как реализовано по факту (Изменения) | Причина изменений / Запросы пользователя |
| :--- | :--- | :--- | :--- |
| **Главное окно** | Стандартное полноразмерное окно Windows с разделами. | Заменено на компактное бесшовное Flyout-окно у трея, закрывающееся при потере фокуса. Размеры расширены до **460x680** для удобства просмотра. | Запросы пользователя №4, №6, №11, №12 (окно расширено для идеального вмещения 8 плиток UniformGrid). |
| **Главная страница** | Большое изображение дня и карусель внизу. | Заменено на единую **галерею-сетку из 8 плиток** с оверлеями при наведении и поддержкой двойного клика. | Запрос пользователя №12 (упрощение и улучшение визуала основного экрана). |
| **Детали обоев** | Было частью главного экрана. | Перенесено на отдельную красивую страницу деталей обоев (ℹ) с крупным превью, подробным копирайтом и ссылкой. | Запрос пользователя №12 (чистый интерфейс галереи, фокус на деталях по кнопке Инфо). |
| **Двойной клик на плитке** | Ничего не делал. | Мгновенно скачивает и устанавливает обои рабочего стола. | Запрос пользователя №12 (быстрое применение прямо из общей галереи). |
| **Страница избранного** | Отсутствовала. | Разработана страница «Избранное» (★) со списком карточек, превью, быстрым применением, показом в проводнике и удалением. | Запрос пользователя №11 (нужен удобный просмотр и управление избранным прямо из окна). |
| **Очистка с диска** | Отсутствовала. | Неизбранные обои удаляются автоматически раз в день. При разизбранствовании файл **моментально стирается с ПК физически**. | Запрос пользователя №11 (интегрирована строгая очистка диска от ненужных больших UHD файлов). |
| **Иконка приложения** | Дефолтная пустая иконка. | Специально адаптированная иконка `icon_tray.png` с автоматической обрезкой прозрачных полей, скомпилированная в многослойный `app.ico` (16x16, 32x32, 48x48, 256x256). | Жалобы на мелкий размер и системную заглушку в трее. |
| **Прокрутка галереи** | Стандартный скроллбар. | Галерея, избранное и детали используют тонкий Fluent-скроллбар (6px), плавающий поверх контента. | Пользователь №6, №11, №12 (выбивалось из стиля, белые широкие полосы ломали стиль Windows 11). |
